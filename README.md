# ტაქტიკური ნიშნების გენერატორი

**ავტორი:** უფროსი სერჟანტი დავით თედიაშვილი

სასწავლო აპლიკაცია დამწყები სამხედროებისთვის. მომხმარებელი ჩაწერს ნიშნის წერილობით განმარტებას და აპლიკაცია ავტომატურად აჩვენებს შესაბამის ტაქტიკურ ნიშანს (APP-6 / MIL-STD-2525) ან ტაქტიკური ამოცანის გრაფიკას (ADP 1-02, FM 3-90).

აპლიკაცია მუშაობს ინტერნეტის გარეშე, მხოლოდ შრიფტები იტვირთება ქსელიდან. ოფლაინ რეჟიმში მათ ნაცვლად სისტემური შრიფტი გამოიყენება.

## საქაღალდის შემადგენლობა

| ფაილი | დანიშნულება |
|---|---|
| `www/index.html` | აპლიკაციის გვერდი |
| `www/symbols-data.js` | **ყველა ნიშნის მონაცემი**: სახეობები, გვარეობები, ეშელონები, მომარაგების კლასები, სპეციალური ნიშნები (`SP`), დავალებები (`TK`), წესები (`RULES`) |
| `www/tasks/` | ტაქტიკური დავალებების გრაფიკა კურსის მასალიდან (PNG) |
| `www/app.js` | ლოგიკა: განმარტების ამოცნობა, ნიშნის აგება, კატალოგი, ვარჯიში |
| `www/manifest.webmanifest`, `www/sw.js` | PWA: ტელეფონზე დაყენება და ოფლაინ მუშაობა |

## 1. გამოყენება კომპიუტერზე

ორმაგად დააწკაპუნეთ **`open-app.bat`**-ზე. ასევე შეგიძლიათ პირდაპირ გახსნათ `www/index.html` Chrome-ით, Edge-ით ან Firefox-ით. ინსტალაცია საჭირო არ არის.

## მონაცემების შემოწმება

`symbols-data.js`-ის ყოველი ცვლილების შემდეგ ორმაგად დააწკაპუნეთ **`check-data.bat`**-ზე (საჭიროა Node.js). სკრიპტი აჩვენებს შეცდომებს და გაფრთხილებებს. GitHub-ზე იგივე შემოწმება ავტომატურად ეშვება ყოველი გამოქვეყნების წინ.

ახალი მასალის შესატანად იხილეთ `data-import/README.md`. განვითარების გეგმა აღწერილია `ROADMAP.md`-ში.

## 2. ტელეფონზე, Android აწყობის გარეშე (PWA)

1. დააყენეთ [Node.js](https://nodejs.org) (LTS ვერსია).
2. ამ საქაღალდეში გაუშვით: `npm run serve`
3. ავტომატური გამოქვეყნება GitHub Pages-ზე: ატვირთეთ საქაღალდე GitHub რეპოზიტორიაში (`main` ბრენჩი), შემდეგ გახსენით Settings → Pages → Source: **GitHub Actions**. ამის შემდეგ ყოველი ცვლილება თავისით გამოქვეყნდება, `.github/workflows/deploy-pages.yml`-ის მიხედვით.
4. გახსენით გვერდი Chrome-ით ტელეფონზე და აირჩიეთ მენიუ → „Add to Home screen“.

## 3. Android აპლიკაცია (APK) — ⏸ დარეზერვებულია, იხ. ROADMAP.md, ეტაპი 3

საჭიროა: Node.js და [Android Studio](https://developer.android.com/studio).

```
npm install
npm run android:add      # ქმნის android/ საქაღალდეს (ერთხელ)
npm run android:sync     # www/ ცვლილებების გადატანა Android პროექტში
npm run android:open     # ხსნის Android Studio-ს
```

Android Studio-ში: **Build → Build App Bundle(s) / APK(s) → Build APK(s)**. საბოლოო ფაილი იქმნება აქ: `android/app/build/outputs/apk/`.

`www/`-ში ყოველი ცვლილების შემდეგ თავიდან გაუშვით `npm run android:sync`.

## ახალი ნიშნის ან ტერმინის დამატება

ყველა ცვლილება კეთდება `www/symbols-data.js`-ში:

- **ახალი ქართული სინონიმი.** დაამატეთ ფუძე შესაბამისი ჩანაწერის `stems` სიაში. მაგალითად `'მსროლელ'`, ჩანაწერში `inf`.
- **ახალი დარგი.** დაამატეთ ჩანაწერი `BR` ობიექტში. თუ ხატულა ახალია, მისი SVG ფუნქცია ჩაწერეთ `ICON`-ში.
- **ახალი დავალება.** დაამატეთ ჩანაწერი `TK`-ში, ხოლო გრაფიკის სურათი ჩადეთ `www/tasks/<img>.png`-ად.
- **ახალი სპეციალური ნიშანი** (პუნქტი, იარაღი, ნაღმი…) — ჩანაწერი `SP`-ში, SVG ფუნქციით.
- **`v:1` / `note`.** ასე აღნიშნულია ის, რაც ოფიციალურ მასალასთან შედარებას საჭიროებს. შემოწმების შემდეგ წაშალეთ.

## სტატუსი და შეზღუდვები

- **სასწავლო პროტოტიპი.** ოფიციალური სახელმძღვანელო არ არის.
- **ქართული ტერმინოლოგია.** სამუშაო ვარიანტია. საქართველოს თავდაცვის ძალების მასალით უნდა დაზუსტდეს.
- **ოფიციალური დანერგვა.** უწყებაში დანერგვამდე საჭიროა შესაბამისი სამსახურების (სწავლება / დოქტრინა, კიბერუსაფრთხოება) თანხმობა და აპლიკაციის ხელმოწერა უწყების სერტიფიკატით.
- **დასაშვები მასალა.** პროექტში შეიტანეთ მხოლოდ საჯარო / გაუსაიდუმლოებელი მასალა.

წყაროები: NATO APP-6; MIL-STD-2525; ADP 1-02 (Terms and Military Symbols); FM 3-90 (Tactics).
