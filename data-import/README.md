# ახალი მასალის შეტანა

ამ საქაღალდეში ინახება საქართველოს თავდაცვის ძალების სიმბოლიკის მასალა, სანამ ის აპლიკაციის მონაცემებში გადავა.

## როგორ შევავსოთ `new-symbols-template.csv`

ფაილი იხსნება Excel-ით. ერთი სტრიქონი შეესაბამება ერთ ნიშანს, ტერმინს ან სინონიმს.

| სვეტი | რა იწერება |
|---|---|
| `type` | `branch` (დარგი), `echelon` (ეშელონი), `task` (ამოცანა), `affiliation`, `modifier` ან `synonym` (ახალი სიტყვა არსებული ჩანაწერისთვის) |
| `key` | არსებული ჩანაწერის კოდი (`inf`, `armor`, `block`…), ახალისთვის — ცარიელი |
| `ka` | ოფიციალური ქართული დასახელება |
| `en` | ინგლისური / NATO დასახელება |
| `stems` | სიტყვის ფუძეები `;`-ით გამოყოფილი, რომლითაც განმარტება უნდა ამოიცნოს (`ქვეით; მსროლელ`) |
| `description` | როგორ გამოისახება / რას ნიშნავს |
| `icon_or_graphic` | არსებული ხატულა ან „ახალი“ |
| `source`, `page` | საიდან არის აღებული (სახელმძღვანელო, გვერდი) |
| `status` | `new` / `verified` |
| `notes` | შენიშვნა |

ახალი ხატულის ან გრაფიკის ფოტო ან სკანი შეინახეთ ამავე საქაღალდეში, ფაილის სახელად კი გამოიყენეთ `key`.

## შემდეგი ნაბიჯი

შევსებული ფაილი და სკანები ატვირთეთ Claude-თან საუბარში. ჩანაწერები გადავა `www/symbols-data.js`-ში და გაეშვება შემოწმება (`check-data.bat`).

**ატვირთეთ მხოლოდ საჯარო / გაუსაიდუმლოებელი მასალა.**
